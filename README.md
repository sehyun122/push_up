# 푸시업 자막 카운터

영상을 보면서 버튼으로 카운트를 찍고, 숫자 자막이 들어간 영상을 다운로드하는 웹앱입니다. 자세인식이나 자동 분석 없이 업로드 직후 편집할 수 있습니다. 영상은 서버로 전송하지 않습니다.

## 사용법

1. **영상 불러오기**로 브라우저에서 재생 가능한 MP4, MOV 등의 영상을 선택합니다.
2. 재생하면서 푸시업을 마칠 때마다 **+1 카운트**를 누릅니다. 해당 시점부터 화면 위쪽 숫자가 1씩 올라갑니다.
3. 재생 위치를 옮겨 카운트를 추가하거나, 목록에서 잘못 찍은 카운트를 삭제합니다. **마지막 입력 취소**는 가장 최근에 추가한 카운트를 지웁니다.
4. **자막 넣은 영상 만들기**를 누르고 완료되면 **영상 다운로드**를 누릅니다.

키보드: 버튼·입력창 밖에 포커스가 있을 때 Space로 재생/일시정지, ↑로 +1.

## 영상 저장

- 원본 비율과 소리를 유지하며 최대 긴 변 1920px, 30fps로 녹화합니다.
- 저장은 영상 길이만큼 걸립니다. 완료될 때까지 화면을 켜 두세요. 취소해도 카운트는 유지됩니다.
- MP4 녹화를 지원하는 브라우저에서는 MP4, 그 외에는 WebM으로 저장합니다. 파일 확장자만 바꿔 변환하지 않습니다.
- 자막은 처음에 0을 표시하고, 카운트를 찍은 시점부터 누적 횟수를 표시합니다.
- 편집 내용을 바꾸면 이전 완성 영상은 초기화됩니다. 다시 만들어 주세요.
- 페이지를 닫거나 새로고침하면 영상과 카운트는 사라집니다.

## 실행 / 배포

외부 패키지 설치나 빌드 없이 정적 파일만 호스팅하면 됩니다.

```sh
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. GitHub Pages에도 폴더 내용을 그대로 올릴 수 있습니다. HTTPS에서는 홈 화면 앱으로도 사용할 수 있습니다.

- `index.html`: 업로드, 재생, 수동 카운트 편집, 자막 합성 및 다운로드
- `sw.js`: 앱 파일 캐시 및 이전 자세인식 모델 캐시 정리
- `manifest.webmanifest`, `icons/`: 홈 화면 설치 정보

자세인식 엔진과 모델은 사용하지 않으며 배포 파일에서도 제거했습니다.
